Colossal Cave Adventure!

This repository holds the first version (aka "CROW0000") of William Crowther's Colossal Cave Adventure.

The original code is in `src/`. The directory `src/` and everything outside of it is supporting material made by others.

Build and run the game with:

```sh
python3 build.py
./advent
```

The original game has no `QUIT` command. Close standard input to exit: press
Ctrl-D on Linux or macOS, or Ctrl-Z followed by Enter on Windows.
